# Idées de Design - Brunka Bank Replica

## Design Sélectionné : Modern Banking with Purple Elegance

### Design Movement
**Néo-Minimalisme Bancaire** - Fusion d'une esthétique bancaire moderne avec des touches de dynamisme et d'accessibilité. Inspiré par les interfaces fintech contemporaines qui équilibrent la confiance institutionnelle avec l'innovation numérique.

### Core Principles
1. **Confiance & Clarté** : Hiérarchie visuelle nette, typographie lisible, espacements généreux pour inspirer la confiance
2. **Dynamisme Contrôlé** : Accents de couleur vibrants (violet, cyan, orange) pour créer de l'énergie sans surcharger
3. **Accessibilité Inclusive** : Contraste suffisant, espacements respirants, interactions claires
4. **Modernité Intemporelle** : Design qui reste pertinent, évite les tendances éphémères

### Color Philosophy
- **Primaire** : Violet profond (#6B46C1) - Confiance, innovation, professionnalisme
- **Accent Secondaire** : Cyan/Turquoise (#06B6D4) - Modernité, fraîcheur, dynamisme
- **Accent Tertiaire** : Orange/Ambre (#F59E0B) - Énergie, positivité, appels à l'action
- **Neutres** : Blanc pur (#FFFFFF) pour le fond, gris foncé (#1F2937) pour le texte
- **Raison** : Le violet évoque la stabilité et l'innovation; le cyan apporte de la modernité; l'orange crée des points focaux d'action

### Layout Paradigm
- **Hero asymétrique** : Texte à gauche, illustration/téléphone à droite (décalé)
- **Sections alternées** : Alternance entre fond blanc et fond gris clair pour créer du rythme
- **Grille flexible** : Utilisation d'une grille 12 colonnes avec des espacements variables
- **Sections en cascade** : Chaque section se chevauche légèrement avec la précédente pour créer de la continuité

### Signature Elements
1. **Icônes géométriques** : Icônes épurées avec des formes géométriques simples (carrés, cercles, lignes)
2. **Cartes avec ombre douce** : Cartes avec ombre subtile et bordure légère
3. **Accents de couleur pointus** : Utilisation d'accents de couleur pour mettre en avant les éléments clés (badges, points de couleur)

### Interaction Philosophy
- **Micro-interactions fluides** : Hover effects subtils, transitions douces
- **Feedback immédiat** : Les boutons changent d'état au survol
- **Navigation intuitive** : Barre de navigation sticky avec logo et menu clair

### Animation
- **Entrées en cascade** : Les éléments apparaissent progressivement lors du scroll
- **Hover effects** : Légère élévation des cartes au survol
- **Transitions de couleur** : Transitions douces entre les états

### Typography System
- **Display Font** : Poppins Bold (700) pour les titres (h1, h2)
- **Body Font** : Inter Regular (400) pour le corps du texte
- **Accent Font** : Poppins SemiBold (600) pour les sous-titres et CTA
- **Hiérarchie** : 
  - H1: Poppins 700, 48px
  - H2: Poppins 700, 36px
  - H3: Poppins 600, 24px
  - Body: Inter 400, 16px
  - Small: Inter 400, 14px
